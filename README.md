This 3D space tracking website project was created to visualize real-time astronomical data and showcase live asteroids orbiting our planet using interactive web technology.

The main 3D canvas introduces a custom-rendered Earth suspended in deep space, letting visitors tilt, rotate, and zoom around the orbital plane in real time. Additionally there are asteroids orbiting the earth.

The data section connects directly to NASA's Near Earth Object Web Service (NeoWS) API, dynamically pulling today's live space telemetry into an interactive table.

The detail feature allows users to click on any active asteroid in the list to reveal its real-world physical metrics, including its estimated diameter, relative velocity, and closest distance of approach to Earth.

The underlying build relies on Three.js for smooth 3D graphic rendering{used Ai to create this feature}, Vite for fast asset bundling and relative texture imports, and a custom GitHub Pages setup with a clean CSS overlay to keep the space interface modern, responsive, and easy to navigate.
